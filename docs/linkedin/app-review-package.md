# LinkedIn App Review Package
Date: 2026-06-08

## App Description
Prometheus Studio is a professional AI-assisted video editing workspace. The LinkedIn integration allows business users to publish a completed video or post to their own LinkedIn profile or organization after explicit confirmation.

## Data Minimization
Prometheus Studio requests only the scopes needed to identify the connected LinkedIn account and publish user-selected content. The app does not scrape LinkedIn, does not automate engagement, does not access unrelated profile data, and does not post without user action.

## Review Use Case
1. User signs in to Prometheus Studio.
2. User connects LinkedIn in Settings, Social Accounts.
3. User opens a completed video export.
4. User selects LinkedIn as a publishing destination.
5. User reviews the caption and publishing settings.
6. User explicitly clicks Publish.
7. User can disconnect LinkedIn at any time.
