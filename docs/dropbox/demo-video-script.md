# Dropbox Demo Video Script
Date: 2026-06-08

## Goal
Show the complete Dropbox OAuth, import, edit, export, and disconnect flow in under 3 minutes.

## Script
1. Open `https://prometheusstudio.tech`.
2. Show footer or visible legal links: Privacy Policy and Terms.
3. Sign in to Prometheus Studio.
4. Open Settings, Social Accounts.
5. Click Connect Dropbox.
6. Complete the Dropbox OAuth consent screen.
7. Return to Prometheus Studio and show Dropbox as connected.
8. Open a project.
9. Click Import Media and choose Dropbox.
10. Select one video file from Dropbox and import it into the media bin.
11. Add the file to the editor timeline.
12. Click Export and choose Dropbox as destination.
13. Confirm export.
14. Show the exported file in Dropbox.
15. Return to Settings, Social Accounts.
16. Disconnect Dropbox and show the connection removed.

## Narration
Prometheus Studio requests only account information, file read, and file write permissions. The user chooses the files to import and chooses when to export. Prometheus Studio does not browse unrelated Dropbox files, does not access teams, and does not share Dropbox data for advertising.
