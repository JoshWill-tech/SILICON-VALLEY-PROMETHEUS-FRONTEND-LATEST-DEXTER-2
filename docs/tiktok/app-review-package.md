# TikTok App Review Package
Date: 2026-06-08

## App Summary
Prometheus Studio is an AI-assisted video editing workspace for creators and businesses. The TikTok integration lets users publish a completed video to their own TikTok account after explicit user action.

## Required Submission Assets
| Asset | Requirement | Prometheus Action |
|-------|-------------|-------------------|

## TikTok Data Usage Statement
Prometheus Studio stores only the access token, refresh token if required, expiration time, TikTok account identifier, and basic profile details needed to publish user-selected videos. Prometheus Studio does not access private messages, does not post without user action, and does not share TikTok data for advertising.

## Website Checklist
- Privacy and Terms are visible without opening a hamburger/menu.
- Website has product details, pricing, contact, and support information.
- The app is functioning during review.
- Demo account credentials are provided only through the secure review portal field.

## Recommended Review Description
Prometheus Studio helps creators edit videos and publish completed exports. TikTok publishing is optional and requires explicit user action. The user connects TikTok, selects a completed export, reviews caption and publishing settings, then confirms publish. The integration does not automate unsolicited posting or access unrelated TikTok data.
