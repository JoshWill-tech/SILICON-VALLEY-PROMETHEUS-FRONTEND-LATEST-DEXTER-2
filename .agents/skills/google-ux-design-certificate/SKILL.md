# Google UX Design Certificate Skill

Use this skill when the work needs a practical UX process that can move from idea to tested interface.

Official source: https://grow.google/certificates/ux-design/

## Apply This

- Define the user, task, pain point, and success metric before UI changes.
- Sketch low-fidelity flows before committing to visual detail.
- Prototype the riskiest interaction before building the whole surface.
- Run quick usability checks for navigation, labels, and conversion flow.
- Include accessibility from the first wireframe, not after polish.

## Prometheus Frontend Rules

- For auth, onboarding, and billing flows, write the user journey before styling.
- For editor changes, define the happy path and two failure paths.
- For mobile, prototype tap targets and navigation before animation.

## Verification

Before coding, produce:

1. User goal
2. Main flow
3. Failure flow
4. Success metric
5. Accessibility concern
