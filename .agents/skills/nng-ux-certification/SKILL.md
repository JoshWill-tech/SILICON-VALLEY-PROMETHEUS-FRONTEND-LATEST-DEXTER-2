# Nielsen Norman Group UX Skill

Use this skill when a frontend decision needs research-grade UX discipline rather than taste.

Official source: https://www.nngroup.com/ux-certification/

## Apply This

- Run heuristic evaluation before visual polish.
- Prefer clarity, recognition, feedback, consistency, error prevention, and recovery over novelty.
- Treat usability testing evidence as stronger than internal preference.
- Use simple language, predictable controls, and stable interaction patterns.
- For premium SaaS/editor workflows, reduce cognitive load before adding cinematic effects.

## Prometheus Frontend Rules

- Persistent controls beat expressive layout changes.
- Export, upload, undo/redo, playback, and billing gates must be findable without relearning.
- Empty states must include the next valid action.
- Any animation that delays task completion needs a business reason.

## Verification

Before implementation, answer:

1. What user task gets easier?
2. What can the user misunderstand?
3. What error state exists and how do they recover?
4. Can this be usability-tested in one session?
