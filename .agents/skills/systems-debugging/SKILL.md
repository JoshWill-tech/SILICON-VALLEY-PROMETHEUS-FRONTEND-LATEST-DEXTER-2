Expert procedural guidance for diagnosing and fixing complex, system-wide issues.

## Instructions
- Always start by gathering environment context (OS, versions, active processes).
- Use `run_shell_command` to inspect logs, system state, and network connectivity.
- Isolate the failure by checking components in isolation.
- Reproduce the issue with a minimal script or test case before attempting a fix.
- Verify fixes across different environments if applicable.
