# Interaction Design Foundation Skill

Use this skill for broad UI/UX reasoning: design thinking, interaction design, user research, accessibility, hierarchy, and product usability.

Official source: https://www.interaction-design.org/courses

## Apply This

- Start from user goals and context, then design the interaction.
- Use progressive disclosure for complex editor workflows.
- Make states explicit: loading, empty, error, success, disabled, focused, selected, and billing-limited.
- Design mobile as a touch workflow, not a squeezed desktop.
- Keep information architecture shallow enough for repeated daily use.

## Prometheus Frontend Rules

- Command-heavy surfaces need grouped tools, meaningful labels/tooltips, and predictable shortcuts.
- Visual hierarchy should separate creation, review, export, and account/billing tasks.
- Research assumptions should be written down when evidence is missing.

## Verification

Check:

1. Is the primary action obvious?
2. Is the next step visible after every state change?
3. Does the layout support scanning under time pressure?
4. Does the design still work without decorative motion?
