Expert procedural guidance for finding and synthesizing official documentation.

## Instructions
- Prioritize official documentation (e.g., MDN, GitHub Docs, Framework Docs).
- Use `web_fetch` or `google_web_search` to find up-to-date information.
- Cross-reference multiple sources to verify accuracy.
- Synthesize findings into clear, actionable advice for the current context.
- Keep a record of "source of truth" links for future reference.
