Expert procedural guidance for generating comprehensive automated tests.

## Instructions
- Analyze the target code to identify all logical branches and edge cases.
- Prefer unit tests for business logic and integration tests for component interactions.
- Use existing testing frameworks (e.g., Jest, Pytest) and patterns.
- Ensure tests are idempotent and don't depend on external state.
- Mock external APIs and services to ensure fast, reliable test execution.
